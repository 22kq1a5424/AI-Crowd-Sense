# 🤖 AI Crowd Sense

AI Crowd Sense is an intelligent crowd monitoring and analysis system that uses Artificial Intelligence and Computer Vision to detect, count, and analyze people in real time. The system helps authorities and organizations monitor crowd density, identify overcrowded areas, and improve public safety during events, transportation, and emergencies.

---

## 🚀 Features

- 👥 Real-time people detection
- 📊 Crowd density estimation
- ⚡ Fast and accurate AI-based detection
- 📱 User-friendly interface

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/AI-Crowd-Sense.git
```

### 2. Navigate to the project

```bash
cd AI-Crowd-Sense
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000/
```

## 📸 How It Works

1. Upload a video or connect a live camera.
2. The AI model detects every person in each frame.
3. The system counts the number of people.
4. Crowd density is calculated.
5. If the crowd exceeds a predefined threshold, an alert is generated.
6. Results are displayed on the dashboard in real time.
